# FORMA

Персональные образы по фото. Бежево-золотая витрина с примерами подборок.

Статический сайт для GitHub Pages. Публикация из main / (root), без сборки.
Внешний сервер заявок находится в Supabase, общение через Telegram.
Секретов и данных клиентов в этом репозитории нет.

Для обновления измените index.html, style.css или showcase.js.
Изображения находятся в assets/, локальные шрифты и лицензии — в fonts/.
